## 🎯 Функционал

### Спринт 1 (базовый)
- ✅ **POST /submitData** — добавление нового перевала

### Спринт 2 (новые методы)
- ✅ **GET /submitData/{id}** — просмотр перевала по ID (включая статус)
- ✅ **PATCH /submitData/{id}** — редактирование перевала (только если статус `new`)
- ✅ **GET /submitData?user_email=...** — список всех перевалов пользователя

### Особенности
- Нельзя редактировать ФИО, email, телефон пользователя
- Редактирование доступно только при статусе `new`
- Автоматическая проверка дубликатов при создании
